# Products Management App


A full-stack web application to manage product categories and their products, built with **ASP.NET Core Web API** on the backend and **Angular** on the frontend.
Supports CRUD operations on categories, nested products, image uploads, and JWT-based authentication.

---

 Features

- ✅ Create, Read, Update, Delete Categories
- ✅ Add multiple Products inside a single Category
- ✅ Upload product images (stored on server, served via static files)
- ✅ Select product Model from seeded lookup data
- ✅ JWT-based user authentication (Register / Login)
- ✅ Responsive UI with Bootstrap 5
- ✅ Angular Signals for reactive state management
